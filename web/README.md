# Jorge Trujillo — Landing de perfil

Landing profesional (Vite + React + TypeScript) con el contenido del perfil Backend / DevOps / AI-Fintech.

## Desarrollo

```bash
cd web
pnpm install
pnpm dev
```

Abre [http://localhost:5173](http://localhost:5173).

## Build

```bash
cd web
pnpm build
pnpm preview
```

## Contenido

- Datos del perfil: `src/data/profile.ts`
- Foto: `public/portrait.jpg`
- Estilos: `src/index.css`, `src/App.css`
